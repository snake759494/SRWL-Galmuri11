# 슈퍼로봇대전 L — 갈무리11 폰트 패치

닌텐도 DS 『슈퍼로봇대전 L』 **한글패치(v0.9.1) 롬의 대사 폰트를
[갈무리11(Galmuri11)](https://github.com/quiple/galmuri) 비트맵 폰트로 교체**하는 추가 패치입니다.

기존 폰트보다 글자가 크고 굵어져 가독성이 좋아집니다.
한글 2,350자(KS X 1001 완성형 전체)를 도트 손실 없이 교체했습니다.

## 적용 방법

이 패치는 **한글패치 v0.9.1이 이미 적용된 롬**에 덧대어 적용합니다.
원본 일본판 롬이나 다른 버전의 한글패치 롬에는 적용되지 않습니다.

1. [xdelta UI](https://www.romhacking.net/utilities/598/) 또는 xdelta3를 준비합니다.
2. 원본 파일로 **슈퍼로봇대전 L 한글패치 v0.9.1 롬**을 선택합니다.
   - MD5: `7AB930182FF9D0F4C4EFC96673E112D6`
3. 패치 파일로 `patch/SRWL_K_v0.9.1_Galmuri11.xdelta`를 선택하고 적용합니다.
4. 적용 결과물 MD5: `36ADDB073C1223510B2BA48B16427DF6`

명령줄 사용 시:

```
xdelta3 -d -s "SRWL_K_v0.9.1.nds" SRWL_K_v0.9.1_Galmuri11.xdelta "SRWL_K_v0.9.1_Galmuri11.nds"
```

## 기술 정보

- 이 게임의 폰트는 파일 시스템이 아니라 **arm9 바이너리 안에 내장**되어 있으며, arm9 전체가 BLZ(backward LZ)로 압축되어 있습니다.
- 글리프 포맷: 셀당 26바이트 = [SJIS 코드 u16] + [12행 × u16 픽셀(상위 바이트가 왼쪽 8픽셀, MSB가 왼쪽)]
- 한글 2,350자는 `가`=0x889F부터 SJIS 유효 코드 순서로 배정되어 있고, 압축 해제된 arm9 기준 0x61EA0부터 연속 배치되어 있습니다.
- 갈무리11 글리프는 12×12 셀 안에 11×11로 렌더링해 넣었으며(ppem 12에서 픽셀 퍼펙트), 나머지 일본어·기호 글리프와 게임 코드는 건드리지 않았습니다.
- 수정된 arm9는 원본과 **완전히 동일한 크기·구조로 재압축**되어 헤더나 체크섬 변경이 없습니다.
- 추출·빌드에 사용한 파이썬 스크립트는 [`tools/`](tools/) 폴더에 있습니다.

## v1.1 — 이미지 한글패치 추가

폰트 교체에 더해 **그래픽(이미지)으로 그려진 일본어 텍스트 225장**을 한글화했습니다.
`SRWL_K_v0.9.1_Galmuri11_IMG.xdelta` 하나로 폰트+이미지가 모두 적용됩니다(적용 방법 동일, v1.0과 같은 v0.9.1 롬 기준).

- 적용 결과물 MD5: `72353088C78EF24FE41C4B4DB9051046`

![이미지 패치 전후](images/img_before_after.png)

### 한글화된 이미지
- **시나리오 제목 카드 55장** — 프롤로그~최종화 전부 (제1화 「쿠로가네로 이끌린 소년들」 등)
- **시간 경과 카드 4장** — 며칠 후…, 1년 후…, 아득한 옛날…, 현재…
- **정신기 발동 컷인 35장** — 열혈, 혼, 집중, 필중, 번뜩임, 불굴, 철벽 등 (그라데이션·이탤릭 원본 스타일 재현)
- **특수능력 발동 6장** — 탄창회복, 마진 파워, 동탁 파워, 제로시스템, 접속, 절단
- **전투 표시 66장** — 베어내기, 쏘아떨구기, 각종 배리어명, 스탯 다운 L1~L3, MAP병기, 합체 공격 등
- **지역명 1장** — 일본/지구권/다리우스계/은하계 에리어

### 원본 유지(의도적)
- 참전작 로고, 반다이남코 로고, 스태프롤, 판권 표기, PLAYER/ENEMY PHASE 등 영문 연출
- 전투 HUD 복합 시트 4장(arc03#2033-2036)은 라벨이 연속 배치라 안전한 교체가 어려워 차기 버전 예정

### 기술 정보 (이미지 패치)
- 아카이브(arc03/arc05) 서브파일 교체 + FAT 재배치 방식, ROM이 약 120KB 커집니다
- ECD 압축 리소스는 엔진이 지원하는 비압축(ECD v0) 형태로 재삽입
- 시나리오 제목은 타일+타일맵(SCR) 재생성, 명조 스타일은 바탕체 AA 렌더를 원본 팔레트 램프로 양자화
